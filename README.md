2026-09-22 更新 B2 主线：阿噗日记位于右上角，小岛占比增大。任务先展示完成条件、建筑解锁、剧情短引子和攻略，点击完成后再进入可跳过的照片/一句话页。五章从日记发现，三章从岛上进入；允许自由顺序阅读，八项任务完成后出现个人回忆录。正式正文和素材继续留空，短引子后续按 Word 替换。

当前入口均引用新版网页；保留旧静态资源文件用于兼容旧缓存。
