# 澳洲大冒险 · 合伙人网页预览

在线预览：https://wenyou990609-collab.github.io/australia-adventure-mvp/mainline/

本分支保存当前 Expo 项目的独立静态网页预览。2026-09-30 更新包含：自然海岛场景与建筑、建筑明信片、地图与旧日记图标、完成八项后的常驻回顾、更新后的生活任务与攻略、日记章节目录和统一手绘笔记本回忆录。

- 小记必须返回目录选章，章头不显示天数；攻略在左，小记在右。
- 回忆录和阿噗日记使用相同笔记本画风；照片和留言仍来自用户自己保存的记录。
- 八项任务完成后开放回忆录；新浏览器从真实空白进度开始。
- 网页进度保存在各自浏览器内，不与本地预览、其他设备或伙伴的进度同步。
- 发布分支：`codex/web-preview`；GitHub Pages 从分支根目录提供网页。
- 构建基础路径 `/australia-adventure-mvp` 只设置在隔离的网页构建副本中。
- 保留旧哈希资源以兼容尚未刷新的页面；所有 HTML 入口均引用当前版本。
- 原 APP 开发目录、依赖、原生构建设置和仓库 main 分支保持原样。
- 字体授权见 `licenses/`；构建标记见 `preview-version.json`。
