# 澳洲大冒险 · 合伙人网页预览

在线预览：https://wenyou990609-collab.github.io/australia-adventure-mvp/

此分支仅保存从当前 Expo APP 独立导出的静态网页，用于演示当前界面、孤岛建设、主线任务和阿噗手写日记。剧情等尚未完成的内容保留占位状态。

- 发布分支：`codex/web-preview`，GitHub Pages 从分支根目录发布。
- 网页构建使用项目子路径 `/australia-adventure-mvp`；该配置仅存在于隔离的网页构建副本。
- 原 APP 的源码、素材、依赖和打包配置均未修改；本分支不参与 Android/iOS 安装包开发。
- 网页进度保存在各自浏览器中，不与 APP 或其他设备同步。
- 仓库 `main` 分支保留之前的网页项目及其历史。
- 字体授权见 `licenses/`。

更新网页时，应在隔离目录重新导出并更新本分支，不能将本分支的路径配置覆盖回 APP 项目。
