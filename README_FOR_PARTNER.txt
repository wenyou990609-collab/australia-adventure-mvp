How to open the demo:

1. Double-click START_SERVER.bat.
2. Wait a few seconds. The web page should open automatically.
3. If it does not open, double-click OPEN_WEB_PAGE.url.

Important:
- Keep the black server window open. If you close it, the web page will stop working.
- On the first run, it may install dependencies for a few minutes.
- If it says Node.js is missing, install Node.js LTS first: https://nodejs.org/
